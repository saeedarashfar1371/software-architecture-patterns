# 04-Runtime Components README (README.md)

## Runtime Components Overview

This section covers the essential runtime components that power modern software systems. These components provide the operational mechanisms for executing tasks, handling messages, and maintaining state.

### Components Covered

1. **Actors**: Independent units of computation that encapsulate state and behavior.
2. **Messaging System**: Handles communication between actors or components using mailboxes, queues, or schedulers.
3. **Persistence & State Storage**: Mechanisms to store actor state, application data, and ensure durability.

## Recommended Learning Path

- Start with **Actors** to understand isolated units of computation and state.
- Explore **Messaging System** to see how communication and scheduling are handled.
- Study **Persistence & State Storage** to understand data durability and consistency.
